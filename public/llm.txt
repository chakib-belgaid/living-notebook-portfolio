# Chakib Belgaid — A living notebook

> Portfolio of Chakib Belgaid, a product engineer with a Ph.D. in software engineering. His work covers applied AI, developer tools, and software energy measurement.

The default experience is an interactive garden with Sketch, Blueprint, Build, and Bloom stages. For text extraction, use the reading page at `?view=read`: it contains the portfolio content in semantic HTML without requiring JavaScript, WebGL, or garden audio. Visitors can select this page through Low-end mode. English, French, and Arabic are available with JavaScript through `?lang=en`, `?lang=fr`, and `?lang=ar`; the static HTML is English.

Whisperbook is an Android app for narrating EPUBs and PDFs on the device. The portfolio links to the v0.1 test APK and its release requirements. Current source features may differ from that downloadable build. The browser voice illustration uses browser-local speech and is not the Android narration engine.

Wattch Core provides Linux energy traces for command-line, Python, and VS Code workflows. The portfolio links to source build instructions and VS Code development setup. Its screenshot uses synthetic traces to illustrate the workflow. The portfolio's rendering meter estimates energy and carbon from browser CPU/GPU time and assumed power; it is not a hardware energy measurement.

The portfolio does not provide reproducible Whisperbook device latency, narration speed, or peak RAM benchmarks, or a reproducible Wattch daemon overhead comparison against a native C RAPL reader. Use the linked project documentation for version-specific capabilities and evidence. Links to PowerAPI organization repositories do not attribute all organization work to one contributor.

Whisperbook is an Android app for narrating EPUBs and PDFs on the device. The portfolio links to the v0.1 test APK and its release requirements. Current source features may differ from that downloadable build. The browser voice illustration uses browser-local speech and is not the Android narration engine.

Wattch Core provides Linux energy traces for command-line, Python, and VS Code workflows. The portfolio links to source build instructions and VS Code development setup. Its screenshot uses synthetic traces to illustrate the workflow. The portfolio's rendering meter estimates energy and carbon from browser CPU/GPU time and assumed power; it is not a hardware energy measurement.

The portfolio does not provide reproducible Whisperbook device latency, narration speed, or peak RAM benchmarks, or a reproducible Wattch daemon overhead comparison against a native C RAPL reader. Use the linked project documentation for version-specific capabilities and evidence. Links to PowerAPI organization repositories do not attribute all organization work to one contributor.

### Z-Image-Turbo · Android

Personal experiment · mobile diffusion inference. Porting image generation to Nothing Phone 3: 512×512 output, a comparison of 100 runtime/precision configurations, INT8/INT4 quantization, and a QNN w8a16 path on the Hexagon NPU. The work includes numerical checks, activation-saturation diagnosis, and calibration across all diffusion steps. Experimental work described in my October dossier. Single-block timings do not establish an end-to-end generation speedup; no public repository is linked here.

### Pocket TTS Android Benchmark

Public benchmark · OnePlus 6T. A pinned English INT8 Pocket TTS conversion running through sherpa-onnx on Android. On a OnePlus 6T with Android 11, CPU and two threads, the recorded real-time factors are 0.94, 1.01, and 1.06 for 2, 4, and 8 diffusion steps. Audio samples and machine-readable measurements are published. One observed run per setting; not averages or a Whisperbook benchmark. RTF is generation time divided by audio duration.

Source: https://github.com/chakib-belgaid/pocket-tts-android-benchmark

### Speculative decoding · MLX

Public experiment · negative result documented. Compared Qwen3 4B with a Qwen3 0.6B draft model on 40 labeled speaker-classification samples. Both paths reached 97.5% accuracy, but speculative decoding was 28.3% slower in the recorded protocol. Short outputs and model loading inside each timed call limit the conclusion. This is not a steady-state serving benchmark.

Source: https://github.com/chakib-belgaid/speculative-decoding-mlx

## BP Log / bp-tracker

A phone web app that reads a blood-pressure monitor’s display from a photo, then lets the user check and correct the values before saving. Image-processing rules handle the display layout; a 10,123-parameter CNN trained on synthetic digits runs in plain JavaScript with a 54 KB weights file. Published evaluation: 91% complete readings on 55 photos from one monitor; 99.5% digit accuracy on 187 held-out digits. The full reading set guided pipeline development, so it is not an independent holdout. Median phone latency: 268 ms across three runs on an Android 10 phone.

Source: https://github.com/chakib-belgaid/bp-tracker

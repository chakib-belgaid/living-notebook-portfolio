# Chakib Belgaid — A living notebook

> Portfolio of Chakib Belgaid, an applied AI and product engineer with a Ph.D. in software engineering. His work covers applied AI, developer tools, and software energy measurement.

The homepage is one guided reading in eight chapters: a left text card over a full-viewport navy night scene, where the same procedural 3D house is drawn as a Sketch, laid out as a Blueprint, built for each project, and in Bloom at Contact. The text is the content. The static HTML is complete semantic content without JavaScript, WebGL or audio; `?view=read` (or `?view=stills`) shows the same page with still images and loads no renderer. English and French are available: the homepage switches with `?lang=en` and `?lang=fr` when JavaScript runs (its static HTML is English), and each case page has a French copy under `/fr/work/<slug>/`. No other language is offered.

Optional demos run only when the visitor asks for them, and nothing is sent anywhere. In the garden panel the visitor can set the hour, a weather preset or live weather from Open-Meteo, and the season, plant up to 24 trees and turn the garden; "Explore the garden" turns and zooms it, with labelled places that link to the chapters; "Save a postcard" downloads a PNG of the arranged garden. "Show rendering detail", in the carbon tally's panel, charts this page's estimated rendering cost from browser CPU/GPU time and assumed power; it is not a Wattch hardware measurement. On the Whisperbook case page, "Inside Whisperbook" steps through book, chapters, voices and audio, and "Listen" reads two lines with a voice already on the visitor's device; it is a browser illustration and is not the Android narration engine. Sound in the garden is off until its own control turns it on.

Whisperbook is an Android app for narrating EPUBs and PDFs on the device. The portfolio links to the v0.1 test APK and its release requirements. Current source features may differ from that downloadable build. Its case page shows four app screenshots (Now Playing, Read Along, Voice Cast, Library).

Wattch Core provides Linux energy traces for command-line, Python, and VS Code workflows. The portfolio links to its source and documentation. Its case page shows two screenshots: dry-run output from a deterministic test scenario, and the Energy Tests surface rendered from a deterministic demo run with synthetic values; both illustrate the workflow, not physical hardware energy. The portfolio's rendering estimate is not a hardware energy measurement either.

The portfolio does not provide reproducible Whisperbook device latency, narration speed, or peak RAM benchmarks, or a reproducible Wattch daemon overhead comparison against a native C RAPL reader. Use the linked project documentation for version-specific capabilities and evidence. Links to PowerAPI organization repositories (pyRAPL, pyJoules) do not attribute all organization work to one contributor.

## BP Log / bp-tracker

A phone web app that reads a blood-pressure monitor’s display from a photo, then lets the user check and correct the values before saving. Image-processing rules handle the display layout; a 10,123-parameter CNN trained on synthetic digits runs in plain JavaScript with a 54 KB weights file. Published evaluation: 91% complete readings on 55 photos from one monitor; 99.5% digit accuracy on 187 held-out digits. The full reading set guided pipeline development, so it is not an independent holdout. Median phone latency: 268 ms across three runs on an Android 10 phone.

Source: https://github.com/chakib-belgaid/bp-tracker

## From the notebook

### Whispbook · web studio

Public source · self-hosted audiobook studio. A React/FastAPI studio for importing and editing documents, assigning character voices, and generating chapter audio with Kokoro or Chatterbox. It exports M4B audiobooks, subtitles, and Python scripts that preserve the edited text and synthesis settings. Separate from the Android app. The current web app does not integrate the separate model-based speaker-attribution experiment.

Source: https://github.com/chakib-belgaid/whispbook

### Pocket TTS Android Benchmark

Public benchmark · OnePlus 6T. A pinned English INT8 Pocket TTS conversion running through sherpa-onnx on Android. On a OnePlus 6T with Android 11, CPU and two threads, the recorded real-time factors are 0.94, 1.01, and 1.06 for 2, 4, and 8 diffusion steps. Audio samples and machine-readable measurements are published. One observed run per setting; not averages or a Whisperbook benchmark. RTF is generation time divided by audio duration.

Source: https://github.com/chakib-belgaid/pocket-tts-android-benchmark

### Speculative decoding · MLX

Public experiment · negative result documented. Compared Qwen3 4B with a Qwen3 0.6B draft model on 40 labeled speaker-classification samples. Both paths reached 97.5% accuracy, but speculative decoding was 28.3% slower in the recorded protocol. Short outputs and model loading inside each timed call limit the conclusion. This is not a steady-state serving benchmark.

Source: https://github.com/chakib-belgaid/speculative-decoding-mlx
